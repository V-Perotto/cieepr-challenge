# Frontend: Cadastro de Candidatos

SPA Angular 22 + Taiga UI 5.26. As instruções de execução (Docker e Compose), os testes e as
versões estão no [README da raiz](../README.md).

Comandos úteis (pnpm 11.21.0):

```bash
pnpm install
pnpm start                  # ng serve em http://localhost:4200 (proxy /api → localhost:3000)
pnpm build                  # build de produção em dist/frontend/browser
pnpm test     # testes unitários (Vitest + jsdom)
```
